## Notes
- [*1]: Golden Json values. The certified luminosity by CMS with normtag by BRIL (see [[TWiki](https://twiki.cern.ch/twiki/bin/view/CMS/PdmVRun3Analysis#DATA)]). Access to Golden JSONs can be found in this [[link](https://cms-service-dqmdc.web.cern.ch/CAF/certification/Collisions24/)][[DC3](https://cmsdc3.web.cern.ch/)].
- [*2]: While doing analysis with prompt DATA, one should take into account all the processing versions. If a specific prompt has v1 and v2, then you should input both of them in your analysis. This is not the case for data reprocessing, in which the general rule is to always use the greatest version number. In addition, due to a DBS bug, there is a run overlap (mistakenly) reported in DAS, even though at the file level there isn't. When computing the integrated luminosity for you analysis, please use the run range provided in the [Run-3 twiki Era definition](https://twiki.cern.ch/twiki/bin/view/CMS/PdmVRun3Analysis#2023_Era_definition).

## Cross-check with DAS / McM (2026-10-16, not from the slide)
- **MC GT**: the slide says `150X_mcRun3_2024_realistic_v4`, but the central production uses `150X_mcRun3_2024_realistic_v2`.
  - All 17112 RunIII2024Summer24 MiniAODv6 / NanoAODv15 datasets on DAS have `realistic_v2` in the processing string (none with v3-v5), and the NANOAODSIM link above also selects `*realistic_v2*`.
  - McM requests checked: GEN-RunIII2024Summer24NanoAODv15-00002 (TTto2L2Nu, CMSSW_15_0_2) and GEN-RunIII2024Summer24NanoAODv15-00718 (DY, CMSSW_15_0_17) both have `--conditions 150X_mcRun3_2024_realistic_v2`.
  - `conddb diff 150X_mcRun3_2024_realistic_v2 150X_mcRun3_2024_realistic_v4` differs only in JEC (`JetCorrectionsRecord`):

    | label | v2 | v4 |
    |---|---|---|
    | AK4PFPuppi | `JetCorrectorParametersCollection_Winter24_AK4PFPuppi_offline_v1` | `JetCorrectorParametersCollection_Summer24_AK4PFPuppi_offline_v1` |
    | AK4PFchs | `JetCorrectorParametersCollection_Winter23_AK4PFchs_offline_v1` | `JetCorrectorParametersCollection_Summer24_AK4PFchs_offline_v1` |
    | AK8PFPuppi | `JetCorrectorParametersCollection_Winter23_AK8PFPuppi_offline_v1` | `JetCorrectorParametersCollection_Summer24_AK8PFPuppi_offline_v1` |

  - This repo follows the slide and uses `realistic_v4` (`scripts/MC_2024.txt`).
