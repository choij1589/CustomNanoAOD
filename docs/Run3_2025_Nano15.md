## Notes
- [*1]: Golden Json values. The certified luminosity by CMS with normtag by BRIL (see [[TWiki](https://twiki.cern.ch/twiki/bin/view/CMS/PdmVRun3Analysis#DATA)]). Access to Golden JSONs can be found in this [[link](https://cms-service-dqmdc.web.cern.ch/CAF/certification/Collisions24/)][[DC3](https://cmsdc3.web.cern.ch/)].
- [*2]: While doing analysis with prompt DATA, one should take into account all the processing versions. If a specific prompt has v1 and v2, then you should input both of them in your analysis. This is not the case for data reprocessing, in which the general rule is to always use the greatest version number. In addition, due to a DBS bug, there is a run overlap (mistakenly) reported in DAS, even though at the file level there isn't. When computing the integrated luminosity for you analysis, please use the run range provided in the [Run-3 twiki Era definition](https://twiki.cern.ch/twiki/bin/view/CMS/PdmVRun3Analysis#2023_Era_definition).

## Cross-check with DAS / CMSSW (2026-10-16, not from the slide)
- **Release**: T0 prompt MiniAOD was made in CMSSW_15_0_6 (C) to CMSSW_15_0_15_patch4 (G), so this is processed in the CMSSW_15_0_22 area.
- **Era**: `Run3_2025` (and `Run3_2025_FtoG`) exist in CMSSW_15_0_22 but not in 15_0_2. `Run3_2025` already includes the `run3_nanoAOD_2025` modifier.
- **Prompt versions**: C and F have two prompt versions with disjoint runs; both are needed per [*2] (checked with Muon0):
  - `Run2025C-PromptReco-v1`: runs 392174-393087, `Run2025C-PromptReco-v2`: runs 393111-393516
  - `Run2025F-PromptReco-v1`: runs 396629-397596, `Run2025F-PromptReco-v2`: runs 397619-397853
  - DAS also has eras A and B, which are not in the table.
- **Golden JSON**: the slide's [link] points to `Collisions24/`. 2025 JSONs are in [Collisions25/](https://cms-service-dqmdc.web.cern.ch/CAF/certification/Collisions25/); latest at the time of check: `Cert_Collisions2025_391658_398903_Golden.json`.
- **MC GT**: this table (and the 2026 one) says `150X_mcRun3_2024_realistic_v2` for Summer24 MC, while the 2024 table says `realistic_v4`. This repo currently uses `realistic_v4` (`scripts/MC_2024.txt`); see [Run3_2024_Nano15.md](Run3_2024_Nano15.md).
